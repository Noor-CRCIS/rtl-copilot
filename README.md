# راست‌چین هوشمند نور

**Noor RTL — VS Code, Copilot & AI Chat**

نمایش خواناتر فارسی و عربی در گفتگوهای هوش مصنوعی، ورودی‌ها، پیش‌نمایش Markdown و کامنت‌های کد؛ با امکان فعال یا غیرفعال‌کردن هر بخش به‌صورت مستقل.

## چه امکاناتی دارد؟

- **گفتگو و متن:** جهت‌دهی متن در بخش‌های پشتیبانی‌شدهٔ Copilot و AI Chat و نمایش فارسی در پیش‌نمایش داخلی Markdown.
- **ورودی‌های خودکار:** تشخیص جهت فارسی و انگلیسی در پرامپت، جستجو، Find/Replace، تنظیمات و Command Palette. ورودی خالی به‌اجبار راست‌چین نمی‌شود.
- **کامنت فارسی:** راست‌چین‌کردن خودکار خطوط مستقل کامنت فارسی، بدون تغییر جهت کد و رشته‌ها.
- **کنترل دلخواه:** روشن یا خاموش‌کردن قابلیت‌ها از Settings یا فرمان «فعال/غیرفعال‌کردن بخش‌های RTL».

## نصب و شروع کار

1. **نصب افزونه:** فایل [نسخهٔ انتشار](https://github.com/Noor-CRCIS/rtl-copilot/releases) را دریافت کنید و از فرمان `Extensions: Install from VSIX...` در VS Code نصب کنید. نام بستهٔ این نسخه `rtl-copilot-2.9.17.vsix` است.
2. **اعمال تغییرات رابط:** در Command Palette، فرمان «نصب مجدد پچ» از گروه «راست‌چین هوشمند نور» را اجرا کنید.
3. **راه‌اندازی دوباره:** تمام پنجره‌های VS Code را کامل ببندید و برنامه را دوباره باز کنید.
4. **استفاده در Remote SSH:** رابط کاربری روی رایانهٔ محلی نمایش داده می‌شود؛ نصب و اعمال پچ باید روی همان VS Code محلی انجام شود، نه فقط سرور.

پیش‌نمایش داخلی Markdown مسیر مستقلی دارد و برای خودش به پچ Workbench نیاز ندارد.

## تنظیم‌های اصلی

در Settings عبارت `rtlCopilot` را جستجو کنید. پس از تغییر تنظیم‌های پچ، «نصب مجدد پچ» و خروج کامل از VS Code لازم است.

- **ورودی‌ها و پرامپت — پیش‌فرض روشن:** تنظیم `rtlCopilot.autoInputDirection` جهت خودکار را کنترل می‌کند. در پرامپت، جهت هر خط با نخستین حرف فارسی یا لاتین مشخص می‌شود و ادامهٔ تایپ آن را عوض نمی‌کند.
- **کامنت‌های مستقل فارسی — پیش‌فرض روشن:** با `rtlCopilot.areas.editorComments` خاموش یا روشن می‌شوند.
- **جهت خودکار کل ادیتور — پیش‌فرض خاموش:** تنظیم `rtlCopilot.autoEditorDirection` مستقل از کامنت‌هاست. برای کنترل دستی فایل‌ها، `rtlCopilot.areas.editorsCode` را روشن کنید.
- **میان‌بر دستی تغییر جهت:** `Ctrl + Shift + Right` خط جاری را راست‌به‌چپ (RTL) و `Ctrl + Shift + Left` آن را چپ‌به‌راست (LTR) می‌کند. `Shift` به‌تنهایی جهت را تغییر نمی‌دهد؛ انتخاب دستی بر تشخیص خودکار مقدم است.
- **تنظیم هر ناحیه:** همهٔ ناحیه‌های پشتیبانی‌شده کلید جداگانه زیر `rtlCopilot.areas.*` دارند. برای ورودی‌ها نیز گروه‌های `promptInputs`، `searchInputs`، `settingsInputs`، `quickPickInputs` و `otherInputs` مستقل‌اند و از کلید اصلی `inputs` پیروی می‌کنند.

> **نکته:** برای اعمال تغییرات تنظیمات پچ، «نصب مجدد پچ» و خروج کامل از VS Code لازم است.

## پیش از فعال‌سازی بدانید

- **تغییر فایل‌های VS Code:** برخی قابلیت‌ها با پچ فایل‌های داخلی برنامه کار می‌کنند و ممکن است هشدار یکپارچگی نصب ایجاد کنند. افزونه پشتیبان تهیه می‌کند؛ دسترسی مدیر، PowerShell یا اسکریپت خارجی را خودکار اجرا نمی‌کند.
- **نصب فقط‌خواندنی:** نسخه‌هایی مانند Snap یا نصب بدون مجوز نوشتن قابل پچ نیستند. از نصب قابل‌نوشتن و رسمی VS Code استفاده کنید.
- **پس از به‌روزرسانی VS Code:** ممکن است پچ به نصب مجدد نیاز داشته باشد. برای بازگشت از فرمان «غیرفعال‌سازی پچ RTL» استفاده کنید؛ اگر هشدار یکپارچگی باقی ماند، نصب رسمی VS Code را Repair/Reinstall کنید.
- **محدودهٔ پشتیبانی:** کامنت بعد از کد در همان خط، Docstring‌هایی که زبان رشته تشخیص می‌دهد، فیلد رمز، Webview افزونه‌های دیگر و پنجره‌های بومی سیستم‌عامل مشمول راست‌چینی عمومی نیستند. کامنت‌ها فقط با توکن معتبر زبان تشخیص داده می‌شوند. نمایش متن ترکیبی به رندرکنندهٔ VS Code نیز وابسته است.
